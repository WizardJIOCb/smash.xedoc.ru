# Лось: район закрыт

Оригинальный рисованный 2D платформер для браузера. Лось в бордовой спортивке освобождает заросший двор от карантина Firewall.

## Первая версия

Три связанные локации, пять противников трёх типов, три отключаемых реле. После отключения мир меняет свет и цвет. Скелетный Лось с деформируемой одеждой, серии рук и ног, воздушные и низкие атаки, бег, присед, инерция шага. Враги со скелетом, замахами, уязвимой фазой, уроном и отдачей. Победа, поражение, повтор участка, меню, управление и общий зачёт сайта с локальным сохранением при отсутствии сети.

Это первый короткий маршрут. Полная карта метроидвании, способность для возврата к закрытому проходу, рывок, парирование и финальный босс Firewall ещё в разработке.

## Управление

| Клавиша | Действие |
|---|---|
| A/D, ←/→ | Движение |
| Shift | Бег |
| W, ↑, пробел | Прыжок |
| S, ↓ | Присед и движение в приседе |
| J / K | Серии рук / ног, включая воздух и присед |
| E | Отключить реле после зачистки |
| Esc | Меню / продолжить |
| R | Повторить участок |
| M | Звук |

## Локальная сборка

Godot Standard **4.7.2**, GDScript, Compatibility, Web templates той же версии. Растровые оригиналы и runtime-ассеты хранятся через Git LFS: после клонирования выполнить `git lfs pull`. Windows: portable Godot ожидается в `.tools/godot/Godot_v4.7.2-stable_win64_console.exe`. Установщик окружения: `tools/install_godot_toolchain.py`. Для форматирования и проверок в `.tools/python` нужен gdtoolkit; GUT включён в проект.

```powershell
.\tools\run.ps1 test
.\tools\run.ps1 build
.\tools\run.ps1 run
```

Открыть http://127.0.0.1:8770/index.html. Экспорт в `build/web` игнорируется Git. Основная сцена `scenes/gyms/district_gym.tscn`; прежние анимационные gym сохранены.

## Публикация

- Домен: https://smash.xedoc.ru
- Каталог: `/var/www/smash.xedoc.ru`, текущая версия через `current` → `releases/<release>`.
- Nginx-конфиг: `deploy/nginx-https.conf`; только `/api/scores.php` передаётся PHP8.3-FPM.
- В релиз входят файлы Web export и `deploy/api/scores.php` в `api/`.
- Рекорды: `/var/lib/smash-xedoc/scores.json`, вне сайта и Git, владелец `nginx`, каталог 0700. Не заменять при обновлении.
- Сертификат Let's Encrypt, автоматическое продление Certbot.
- Откат: вернуть симлинк `current` на предыдущий релиз. Первый релиз не заменял существующий сайт.

Общий зачёт любительский: сервер вычисляет очки, проверяет границы и время, выдаёт одноразовые токены забега, ограничивает частоту. Игровое состояние остаётся клиентским; это не защищённый соревновательный рейтинг. Имя до 20 символов, топ10 на экране, до 50 результатов на сервере.

## Графика и лицензии

Оригинальные герои, противники, окружение и промпты: `art/`. Runtime: `assets/`. Новые рисунки созданы встроенным image_gen; нарезка и alpha fitting воспроизводимы через `tools/prepare_enemies.py`. Для Лося — `tools/slice_moose.py`. Manrope: SIL OFL, текст лицензии в `assets/fonts/Manrope-OFL.txt`. Сторонние addons сохраняют свои лицензии. Референсы в `.studioigor` не являются игровыми ассетами.

## Проверки

17 GUT tests: IK, слои и веса, шаг, буфер комбо, однократный урон и подсчёт очков. `tools/district_route_review.tscn` проходит маршрут обычными игровыми командами без изменения здоровья или врагов, используется с `tools/capture.gd`. Он исключён из Web export. API проверяется `python3 tools/test_scores_api.py deploy/api/scores.php` на хосте с PHP8.3: изолированное временное хранилище, публичные рекорды не затрагиваются.
